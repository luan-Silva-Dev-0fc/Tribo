## 📱 Sobre o Projeto

**Tribo** é um aplicativo mobile de rede social desenvolvido com **React Native** e **Expo**, focado em criar conexões genuínas entre pessoas. A plataforma permite que os usuários compartilhem momentos, interajam em tempo real e construam suas comunidades — suas tribos.

## 🚀 Tecnologias

- **React Native** — Interface mobile nativa
- **Expo** — Framework e plataforma para React Native
- **Supabase** — Backend (autenticação e banco de dados)
- **Socket.IO** — Comunicação em tempo real
- **React Navigation** — Navegação entre telas
- **Google Sign-In** — Autenticação com Google
- **Expo AV / Video** — Reprodução de mídia
- **Expo Notifications** — Notificações push

## 📋 Pré-requisitos

- [Node.js](https://nodejs.org/) (v18 ou superior)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- Conta no [Supabase](https://supabase.com/) (para o backend)

## ⚙️ Instalação

```bash
# Clone o repositório
git clone https://github.com/luan-Silva-Dev-0fc/Tribo.git

# Entre na pasta do projeto
cd Tribo

# Instale as dependências
npm install

# Crie o arquivo .env com suas variáveis de ambiente
# (veja .env.example para referência)

# Inicie o projeto
npx expo start
```

## 🔐 Variáveis de Ambiente

Crie um arquivo `.env` na raiz do projeto com as seguintes variáveis:

```env
EXPO_PUBLIC_API_URL=<url_do_seu_servidor>
EXPO_PUBLIC_YOUTUBE_API_KEY=<sua_youtube_api_key>
```
